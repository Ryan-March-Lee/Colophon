三条核心流程

每一步都标了「界面 / 系统动作 / 边界」。绿色是这一步的关键动作；边界不是错误提示，而是产品承诺。

导入：从 PDF 到一条可检索、可打标的记录

批量先入库、再补全；失败不留半条脏数据。

系统动作

阅读器只读：翻页、缩放、旋转，记住上次页码；底部打标条常驻。

系统动作

用户打开阅读器后可随时在右侧打标；原文不遮挡，可继续滚动。

边界

不阻断、不锁滚动；可随时收起。整理状态按元数据与标签自动显示。

系统动作

补全已有标签；AI 从摘要 / 全文提候选；相似标签提示合并。

边界

新标签与旧标签高度相似 → 只提示，不自动合并。AI 建议永不自动写。空标签允许保存。
